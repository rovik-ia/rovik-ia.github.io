# Informes diarios

La rutina en la nube escribe aquí un informe por día (`AAAA-MM-DD.md`) con lo publicado y el estado del sitio.

Las cifras de clics, pedidos y comisiones solo están en el panel de Amazon Afiliados
(https://afiliados.amazon.es/home/reports) y requieren iniciar sesión.

**Privacidad:** este repositorio es público. Los CSV de ventas que se guarden en `reports/ventas/`
están excluidos de git y nunca se suben, así que la rutina en la nube no puede leerlos. Consulta las
ventas directamente en el panel de Amazon.
